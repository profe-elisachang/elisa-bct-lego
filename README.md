📖 BCT 數位教材自動化專案 (README)
🎯 專案願景
本專案旨在將 BCT (Business Chinese Test) 教材數位化，並轉化為一個具備「高互動性」與「動態擴充性」的學習平台。核心目標是讓 Elisa 老師在課堂上能即時補充，並讓學生能自動複習。

💡 核心教學邏輯
本專案不只是「搬運課本」，而是基於以下三大教學痛點的解決方案：
1. 內容與結構分離 (The Lego Method)
痛點：過去直接修改 HTML 容易導致網頁崩潰，且 AI 生成長代碼易出錯。
方案：HTML 只是「外殼樣板」，內容全部存在 Markdown 檔案中。更新內容只需要改文字，網頁永不壞掉。
2. 動態時間軸 (Live Class Stream)
痛點：課堂上的即時補充（語法、文化、新詞）容易散落在各處，學生難以複習。
方案：在每一課下方建立「時間軸」。老師上課補充的內容會自動按日期排序，並同時匯總到全站的 Timeline 頁面，形成專屬的學習日誌。
3. 三行視覺標準 (The Trio-Line UI)
痛點：成人學習者對漢字與拼音的視覺優先級有需求。
方案：嚴格執行「拼音(綠) / 漢字(黑大) / 英文(灰)」的垂直排列

🛠️ 技術架構
託管：GitHub Pages。
資料庫：Firestore (用於即時同步課堂筆記)。
內容格式：Markdown (.md) + JSON。
複習引擎：基於 Leitner 系統的自定義 SRS 漢字複習網頁。

📂 資料夾導覽
/data: 存放 BCT 各課的 Markdown 內容。
/js: 包含 loader.js (內容加載器) 與 components.js (練習組件)。
template.html: 核心分頁樣板（對話、短文、詞彙、練習）。
Timeline.html: 全局課堂紀錄匯總頁。
